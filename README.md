# REST API Сервис заметок (Практическая работа)

## Описание
Веб-сервис для создания, просмотра и удаления заметок и категорий с поддержкой базы данных SQLite.

## Технологический стек
- Python 3.10
- Flask / Flask-SQLAlchemy
- Pytest
- Docker
